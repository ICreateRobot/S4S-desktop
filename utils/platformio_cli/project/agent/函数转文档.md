# 函数文档转换规范

## 函数名提取规则

函数名格式为 `fMap_` + 功能名称，提取时**去掉 `fMap_` 前缀**。

```c++
static int fMap_init(udc_pack_t *pack)      →  init
static int fMap_clear_screen(udc_pack_t *pack)  →  clear_screen
static int fMap_set_text_size(udc_pack_t *pack)  →  set_text_size
```

------

## 函数形参提取规则

### 参数提取宏说明

函数使用 MicroPython C 接口风格的参数提取宏：

| 宏/函数                                                      | 说明                                   |
| :----------------------------------------------------------- | :------------------------------------- |
| `function_map_udcpack_get_param_int(pack, id, &val)`         | 提取必需 `int` 参数，不存在则报错      |
| `function_map_udcpack_get_param_double(pack, id, &val)`      | 提取必需 `float` 参数，不存在则报错    |
| `function_map_udcpack_get_param_string(pack, id, &val)`      | 提取必需 `string` 参数，不存在则报错   |
| `function_map_udcpack_get_param_int_default(pack, id, &val)` | 提取 `int` 参数，不存在则使用默认值    |
| `function_map_udcpack_get_param_double_default(pack, id, &val)` | 提取 `float` 参数，不存在则使用默认值  |
| `function_map_udcpack_get_param_string_default(pack, id, &val)` | 提取 `string` 参数，不存在则使用默认值 |

> `function_map_udcpack_id(n)` 用于指定参数索引，从 0 开始。

### 参数类型映射

| C++ 类型      | 文档类型 | 示例           |
| :------------ | :------- | :------------- |
| `int`         | `int`    | `int: x`       |
| `double`      | `float`  | `float: value` |
| `std::string` | `string` | `string: text` |

------

## 函数分类与命名规范

根据功能类型，函数命名应遵循以下规范：

| 功能类型  | 命名前缀              | 示例                              |
| :-------- | :-------------------- | :-------------------------------- |
| 获取信息  | `get_`                | `get_distance`, `get_state`       |
| 设置参数  | `set_`                | `set_text_size`, `set_color`      |
| 控制运行  | `run`, `play`, `stop` | `encoder_motor_run`, `music_play` |
| 学习/校准 | `study`               | `gray_study`, `face_study`        |
| 清除/重置 | `clear`, `reset`      | `clear_screen`, `clear_color`     |

------

## 返回值规范

| 返回值类型 | 说明                     | 示例                      |
| :--------- | :----------------------- | :------------------------ |
| 无         | 函数执行成功，无数据返回 | `无`                      |
| 字符串数值 | 返回测量值或状态值       | 距离数值字符串（单位 cm） |
| 版本信息   | 三段式版本号             | `0.1.0`                   |
| 状态字符串 | 功能状态或属性           | `1` 表示是，`0` 表示否    |

## 转换示例

### 示例一：必需参数

```c++
static int fMap_print(udc_pack_t *pack)
{
    int x, y;
    std::string str;
    function_map_udcpack_get_param_int(pack, function_map_udcpack_id(0), &x);
    function_map_udcpack_get_param_int(pack, function_map_udcpack_id(1), &y);
    function_map_udcpack_get_param_string(pack, function_map_udcpack_id(2), &str);
    hw_esp_oled.print(x, y, str.c_str());
    return 0;
}
```

**转换结果：**

#### print

```plain
print(int: x, int: y, string: str)
```

向屏幕缓冲区写入字符。

**参数**

- **x**: 起始 X 坐标
- **y**: 起始 Y 坐标
- **str**: 写入的字符串

**返回值**

无

------

### 示例二：带默认值的参数

```c++
static int fMap_print(udc_pack_t *pack)
{
    int x=0, y=0;
    std::string str;
    function_map_udcpack_get_param_int_default(pack, function_map_udcpack_id(0), &x);
    function_map_udcpack_get_param_int_default(pack, function_map_udcpack_id(1), &y);
    function_map_udcpack_get_param_string(pack, function_map_udcpack_id(2), &str);
    hw_esp_oled.print(x, y, str.c_str());
    return 0;
}
```

**转换结果：**

#### print

```plain
print(int: x=0, int: y=0, string: str)
```

向屏幕缓冲区写入字符。

**参数**

- **x**: 起始 X 坐标；默认值为 0
- **y**: 起始 Y 坐标；默认值为 0
- **str**: 写入的字符串

**返回值**

无

### 示例三：无参函数（带返回值）

```c++
static int fMap_get_distance(udc_pack_t *pack)
{
    int ret = 0;
    uint16_t distance;
    ret = hw_cultr.get_distance(distance);
    comm_uart.send_bytes(std::to_string(distance));
    return ret;
}
```

**转换结果：**

#### get_distance

```plain
get_distance()
```

获取超声波传感器测量到的距离。

**返回值**

距离数值字符串（通常单位为 cm）。

## 完整文档格式模板

每个设备模块应包含以下结构：

```markdown
### 设备名称（`标记值`）

---

#### function_name
```

function_name(int: param1, string: param2)

```plain
函数功能描述。

**参数**

- **param1**: 参数1说明
- **param2**: 参数2说明

**返回值**

返回值说明
```

## 特殊参数说明规范

对于具有特定取值范围的参数，应在说明中明确标注：

| 参数类型 | 说明格式                     |
| :------- | :--------------------------- |
| 枚举值   | `0:停止, 1:开始, 2:重新播放` |
| 范围值   | `0-255` 或 `0 ~ 100`         |
| 特殊标记 | 使用表格或列表说明           |
| 端口选择 | `0:内部IIC, 1:外部IIC`       |

------

## 注意事项

1. **参数索引**：`function_map_udcpack_id(n)` 中的 `n` 从 0 开始，对应文档中的参数顺序
2. **字符串引号**：文档中 `string` 类型的示例值必须包含引号，如 `"text"`
3. **缺省标记**：使用 `_default` 后缀的提取函数，必须在文档中标注默认值
4. **单位标注**：返回值带有物理量纲时，应注明单位（如 cm、秒、度等）
5. **版本格式**：版本类返回值统一使用三段式格式（如 `0.1.0`）
6. **函数间隔**：在提取的两个函数之间，使用 "---" 作为间隔。
